# 肌电每次开机人工确认左右

两套支持的肌电设备先显示为 A、B。A/B 是当前数据流的临时编号，不表示身体左右；序列号只识别设备，不决定佩戴位置，也不沿用旧配置或历史左右绑定。支持型号由 `auto_discovery.emg_usb_ids` 的 VID/PID 确定，默认 `1a86:55d3`；该型号任意两套不同、非空唯一序列号均可使用。这不代表支持任意 USB 设备或新的数据协议。

## 操作

连接两套设备并戴好臂环，在设备确认页面按 A；如果腕部相机也需确认，先完成相机流程，然后进入肌电人工确认。空闲且没有采集进程时，也可按 D 重新确认肌电。

网页同时显示 A、B 的实时肌电波形。操作者可分别握拳、放松，亲自观察哪一组对应身体哪一侧，再选择实际左臂对应的 A 或 B，点击“确认左右”。另一组随之分配为右臂。没有预选项；按键 A 只重播提示，不能代替网页中的明确选择。按 B 可重新开始。

软件不按肌电幅度、运动强度或 IMU 自动识别左右，不提供自动建议，也没有动作阈值或用力要求。实时数据存在性和设备身份检查仅用于保证确认的是当前显示的数据流，不能证明操作者的左右选择正确。

## 有效期

- 同次 Pi 开机且连接、设备和佩戴位置不变：可以复用人工确认。
- Pi 重启、肌电拔插、连接代数变化、换设备或增加第三套设备：旧确认失效，需要重新确认。
- 不拔线直接交换佩戴位置或重新佩戴，软件不能检测；操作者必须主动按 D 重新确认。
- 只连接一套时可显示为 A，但不能生成双设备左右确认；多于两套、序列号缺失或重复等身份不明确时，不任意选择两套。
- 腕相机仍使用自己的左右确认流程，两类结果分别保存和校验。

## 数据与记录

结果保存到 `runtime/emg_calibration.json`，版本为 2，方法为 `manual_emg_preview`。内容包含人工确认标记、boot_id、两套当前连接身份及代数、预览来源路径、左右路径、确认时间和唯一编号。旧版 `alternating_arm_motion` 的 IMU 自动标定结果不能作为新版人工确认使用。

控制器核对本次人工确认会话、实时预览编号、两路来源路径与新鲜数据，并在停止预览后再次检查设备连接身份。准备采集时必须已有有效确认。每段的固定 `device_config.emg_calibration_status` 保存完整确认结果，之后运行时重新确认或失效不改写此前记录。

此流程只给当前数据流赋予身体左右标签，不重排原始 8 通道、不改变 ADC 数值，不修改历史记录，也不启动旧的 IMU 探测程序。软件回归覆盖明确选择、旧结果拒绝、身份变化、预览来源一致性、固定记录及禁用兼容；它不能替代操作者佩戴设备后的真实观察验证。

人工指定肌电期间，预览持有采集占用锁，保证当前确认的来源不会被另一路采集抢占。普通空闲预览沿用现有交接方式，使已完成会话的导出仍可运行。
