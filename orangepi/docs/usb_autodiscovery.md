# USB 自动发现与重新插拔

适用：Orange Pi / Ubuntu 20.04 / ROS Noetic，控制和采集使用 Python 3.8，框架及质检使用 Python 3.11。新增模块仅使用 Python 标准库和现有依赖。

## 使用行为

`configs/devices.yaml` 中 `auto_discovery.enabled: true` 启用自动发现。原来的端口仍作为首次匹配线索，实际连接从 Linux sysfs 和 `/dev` 枚举，不要求手动修改 ttyACM、video 编号。

- 当前支持自动发现 USB ID `0bda:5858` 的腕部相机，以及 `1a86:55d3` 的肌电接收器。其他型号须确认协议和视频格式后再扩展白名单。
- 主控处于设备确认、空闲或无录制进程的错误等待状态时，每约 2 秒检查插拔变化，变化后重新检测有效数据。完成扫描通常还需要 3–4 秒；语音提示可能额外等待网络。
- 已找到接收器但没有数据时，每约 15 秒重试。状态不变时不会重复播报。
- 仍保留 A 键确认本次可用设备、B 键手动重扫的操作。设备清单变化后重新确认即可，不需要编辑路径配置。
- 准备、录制和写盘/质检期间不启动第二个设备读取器，不在同一条录制中换入其他设备。断线沿用原程序的停止及错误处理；在设备释放后重新发现，开始新的录制。
- 物理连接存在不等于采集正常。扫描状态包括 `missing`（没找到）、`no_data`（找到但没收到有效数据）、`ready`（可以读到数据）和 `error`（读取错误）。

## 两台相机的左右问题

**2026-10-09 更新：启用 `wrist_calibration.enabled` 后，以 [每次开机标定规则](wrist_boot_calibration.md) 为准。** 每次 Pi 开机通过交替遮挡指定左右，同次开机的多段录制和采集服务重启复用结果；相机拔插使结果失效。不拔线而互换佩戴位置时，在设备确认或空闲状态按 C 重标定。下面的端口绑定说明仅描述自动发现层，不能作为本次开机左右已确认的依据。

现有两台 USB Camera3 使用相同序列号 `200901010001`。软件可以发现两个独立视频源，但无法仅靠这个序列号辨认物理左、右相机。

程序将首次自动分配且未经确认的相机标为“腕部相机 A/B（左右未确认）”，肌电替换接收器同样使用中性标签。历史数据格式要求保留 `cam_left_wrist`、`cam_right_wrist` 等逻辑目录名，但本次真实标签、端口和 `role_confirmed` 会写入 `device_selection.json` 和 `meta.json` 的 `device_config`；不能仅凭目录名推断物理侧别。

绑定保存在 `runtime/device_bindings.json`。同一插孔重新接入不会因 `/dev/video*` 编号变化交换逻辑角色；整个 Hub 换口时会尝试匹配唯一的末级端口组合。接收器有唯一序列号时可跨插孔追踪。

两台同序列号相机互换物理插孔，系统无法知道哪一台被交换。需要保持已标记的左右插孔，或再次通过遮挡镜头等方式确认；软件不会宣称能从重复序列号恢复物理左右。移动到无法可靠匹配的新端口时，新的自动分配会标为未确认。

## 每段录制固定设备

主控在 `device_selection.json` 中保存完整的已解析 `device_config`，框架通过 `ORANGEPI_DEVICE_SELECTION` 将该快照传给硬件子进程。硬件子进程全程使用快照，不因后台新插设备而更换采集来源。

## 肌电没有数据时

既有驱动直接以 921600 波特率读串口，使用 29 字节、D2 D2 D2 帧头、AA/BB 类型协议，读取 8 通道肌电及臂环 IMU。它不发送配对命令或设备特有的启动命令。

USB 接收器识别成功但无字节输出时，仍需核对本体开机、接收端连接及设备协议。自动配置不能替代设备自身开始输出数据；程序会保持 `no_data` 并重试，不生成假信号。

## 验证

在项目根目录运行 `bash orangepi/scripts/check.sh`，脚本按两套 Python 环境执行各自的测试。新增覆盖包括旧路径失效、重复序列号、枚举顺序变化、单台重连、Hub 上游变化、接收器跨插孔、过多候选设备、录制期间禁止重扫、无数据重试以及录制配置快照。

有设备空闲时，可在加载 ROS 环境后运行 `orangepi/.venvs/ros/bin/python orangepi/src/orangepi_collect/acquisition/scan_devices.py` 检查实时状态。不要在另一个程序录制时手工运行扫描。
