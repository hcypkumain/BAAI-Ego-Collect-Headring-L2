# 腕相机：自动曝光是否允许改变帧率

正式8765和独立诊断8879均提供同一设置，作用于两只腕相机。

- 保持相机当前设置：不发送控制写入；读回并展示当前值。
- 不允许：将 exposure_auto_priority 设为0，自动曝光本身仍保留；低光画面可能更暗，不保证没有其他丢帧或能稳定30fps。
- 允许：将 exposure_auto_priority 设为1，允许自动曝光动态改变帧率，低光可优先亮度。

默认保持，不替采集者选择。设置在设备空闲时修改，两腕查询/设置/读回成功后才持久保存；失败尝试恢复更改前实测值，并保留失败及恢复详情。相机缺失时标记待应用，unsupported不伪称成功。准备/录制/QC及诊断交接中禁止修改。

唯一偏好写入由正式控制器动作队列处理；诊断页面转发，应用同一runtime/wrist_camera_preferences.json。项目配置入口注入偏好，采集device_selection.json快照冻结本段值。UvcSource在打开设备时应用并读回。预览每腕控制报告与采集流camera_controls.json记录实际值；capture_summary也保留控制报告。

该功能不修改JPEG/H.265路径、PTS、码率、颜色、QC阈值，也不解决已有MP4时间压缩问题。

验证：新增硬件控制事务与回滚、界面状态/锁、诊断转发单元测试；现场用空闲预览确认0/1读回并恢复用户原值；没有为此自动启动新录制。
