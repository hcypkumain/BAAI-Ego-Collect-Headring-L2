# 2026-11-19 通用版本

本版本基于 `c4c00f1`，保留此前手机网络断线提示、自动重连与采集准备优化。采前默认不进行脑电阻抗测量；EEG 仍必须在线并提供新数据，其他必需设备和最终开录检查继续执行。记录标明“未测阻抗”，不填造测量值；此前真实测量记录仍按原凭据验证。历史跳过记录使用记录内身份和在线证据核验，证据不全仍会报错。

脑电采集模式的左右肌电按相邻样本判断：间隔超过 10 ms 警告，超过 150 ms 报错。腕带 IMU 仍按原 100 ms 配置检查。异常恢复采用现场 100 ms 的连续缺口和窗口边缘证据限制。此次发布不会重新执行历史段质检。

删除已保存采集会保留回收站和事务凭据；当账本及参考图映射能够证明对应关系且没有其他保留段占用时，恢复相关已保存计数和已完成任务状态。若证据不足，手机明确显示段已删除但进度需要人工核对；若被删段是当前占用者且同一参考图还有另一有效段，则保守拒绝删除，需人工核对，不会自动转移占用。中断后的事务可重放。

发布包包含手机网页更新；已签名 Android v5/v10 APK 沿用原文件，未更换签名。此源码与远端独立分支不表示已经安装到头环。软件测试使用隔离目录；实际手机端删除完整流程与更广泛设备实测尚待验证。
