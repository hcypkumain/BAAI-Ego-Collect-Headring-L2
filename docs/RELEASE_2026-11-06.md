# 2026-11-06 采集程序更新

此版本同步当前采集程序，包含已在 7、11、14 号启用并逐文件核验的 `headring-common-20261106-v3`。公共模块的相对路径和 SHA-256 记录在 `deployment/manifests/headring-common-20261106-v3.json`；设备编号、标定、任务图库、任务进度及运行数据不随代码发布。

## 采集与预览

- 准备完成、正式 START 前可切换任务列表并自选参考图。参考图、准备段元数据和队列同步更新，保留已准备的采集进程；正式开录和隐私确认期间拒绝切换。
- 手机切换预览来源时先完成旧流交接，使用无帧恢复机制；同步发布对应的 H264、JPEG 和媒体服务依赖。
- 板载 IMU 重复或倒退的源时间戳保留原值和样本，记录告警与取证计数；写入溢出等采集失败仍按错误处理。该处理并未证明驱动时间戳异常的硬件根因已消除。

## 肌电与质检

肌电和板载 IMU 使用原始框架的对应检查，未使用此前讨论过的 15ms/3s 肌电验收替代规则。原始肌电重复时间戳及超过 100ms 的时间间隔仍可产生 ERROR；序号丢帧率超过 0.1% 属于原始 WARN。WARN 允许继续，ERROR 保留。

对已验证的稀疏拼接坏行，先备份原始文件、验证嵌入帧头和序号关系，再修复并重新质检。支持已验证的 7/24 字节偏移，拒绝歧义或无法确认的损坏，不将未知错误直接改为 WARN。

肌电信息统一显示左右侧、具体原因、异常时间及处理建议；同步语音、采集结果摘要和历史回看。即时肌电检查与完整主机质检区分：`emg_only` 结果不代表所有模态最终通过；待主机检查的段保留 `pending_qc` 状态并限制上传。默认未配置 `qc_execution.json` 时仍执行完整采后检查；页面可选择执行模式。

同时同步当前程序依赖的任务分块、只读 USB 任务导入、当日采集统计、待主机质检状态和标准化导出接口。标准化导出桥接仍需单独安装对应的主机转换工具，仓库不包含该工具的运行环境。

## 当前运行环境

当前 Pi 程序已经停用脑电/阻抗采集入口，硬件入口使用系统 Python 3.8、`.venvs/hardware` 和 GI/GStreamer；框架使用独立 Python 3.11。原始通用框架中的 EEG 模块及历史文档用于追溯，不是当前 Pi 启动入口。旧虚拟环境不在更新中删除。

已删除不再使用的 `legacy/alternate-project` 备用程序、旧 Pi 脑电/阻抗实现与相应测试、ROS/EEG 环境定义及停用 EgoRecord GUI 的服务入口。快照导出工具同步取消旧 checkout 的再次打包；需要追溯时使用 Git 历史。当前采集/QC 所需的原始通用框架及厂商运行文件继续保留。

部署前阅读 [部署说明](DEPLOYMENT.md)。采集完成并保存后才替换代码，媒体文件也需安装到 `/opt/pi-phone-media`，随后重新启用采集与媒体服务。现有各机配置应独立保留；这次向 Git 推送代码不会再次操作现场服务。
