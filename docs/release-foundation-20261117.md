# 头环整合基础版（2026-11-17）

此分支以通用离线版及 17、22、23 号现场修复为基础，供后续开发使用。设备采集配置、参考图库、任务进度、标定、数据和账号凭据不属于源码发布内容。

## 已整合

- 已保存次数驱动的图片和文字任务轮转、历史状态兼容；肌电与脑电切换均需确认，取消不发送切换请求；质检结果和保存结果独立记录。
- 每日 TXT 统计等待后台刷新，手机导出错误分类、待保存文件恢复和安全的并发处理。
- 当前头环活动网络地址显示；手机经已验证 USB 代理在空闲时同步设备时间，校时保留时间源锁、采集租约、设备与上下文校验。已在 23 号实测同步。
- U 盘参考图 ZIP 只读自动挂载、扫描和导入；数据导出自动挂载、复制校验、事务恢复及安全卸载。23 号已用独立测试数据实测 SHA-256 导出和隔离图库导入，测试文件已清理，未改动正式图库或采集数据。
- 23 号官方脑电阻抗支持：仅当设备本地提供官方 SDK 0.2.0 时启用；其他设备沿用原有后端。已保留 23 号原有 SDK 和 U 盘机制。
- 采集出错或关键收尾证据无法核验时，重采清理路径拒绝删除对应文件；并不能恢复断线期间没有写入的数据。

## 安装与安全边界

使用 `deployment/phone-usb-entry/build_bundle.py` 从冻结 profile 构建，包内含 139 个采集源文件、手机校时与 U 盘挂载所需的受限特权助手。安装器按设备身份、捕获租约、U 盘操作锁、源码前置哈希、依赖和 root 助手已知哈希进行预检；检测到未知现场改动或正在采集、导入、导出时拒绝覆盖。失败使用事务备份回滚，任务状态升级不能通过旧读取器直接回退。

参考图导入所需硬件 Python 环境必须提供 Pillow 与 PyYAML；目标需要 lsblk、findmnt、mount、umount、visudo、chrony 和支持目标 U 盘文件系统的内核或驱动。官方 SDK 是设备环境依赖，不随此源码包分发。

23 号已部署整合源码并实测手机校时和 U 盘隔离读写；其他设备尚未逐台升级或进行硬件验收。候选安装包必须逐台进行预检，现场已有独立改动时先核对合并，不应强制覆盖。升级不会修复物理接口、供电或线缆故障，也无法补回未写入的采集样本。

23 号此前通过独立事务安装过设备专属源码；当前通用安装器对这些不同于原托管发布的文件会安全拒绝覆盖。后续升级该设备须先制作并核验针对 23 号的迁移前置哈希，不可绕过检查。
