# 无显示屏连接蓝牙耳机

流程语音由 Pi 播放，耳机与 **Pi** 建立蓝牙连接。手机只是配置与状态界面，不承担音频转发。

## 首次连接

1. 耳机开机并置于配对模式。若手机正在占用耳机音频，可先断开手机上的连接。
2. 手机与 Pi 连接同一网络，打开 `http://<Pi-IP>:8765/phone`，整页刷新一次。
3. 点击总览的“耳机设置”，或进入“连接设置 → 蓝牙耳机”。点击“搜索耳机”。
4. 在列表中选择自己的耳机，点击“连接并保存”。配对、信任和连接由 Pi 后台处理。
5. 等待“音频通道：已就绪”，再点击“试听提示音”，确认声音确实从耳机传出。

系统同时检查蓝牙连接和实际 A2DP 输出设备，因此不会只因蓝牙显示已连就宣称语音可用。
配对通过 BlueZ 的应用级 `NoInputNoOutput` agent 完成，无需 Pi 显示屏或桌面确认窗口；
只对用户明确选择的耳机执行配对/信任操作。参见 [BlueZ Device API](https://bluez.readthedocs.io/en/latest/device-api/) 与 [Agent API](https://bluez.readthedocs.io/en/latest/agent-api/)。

## 保存与自动重连

BlueZ 保存配对关系，本机 `configs/headphone_selection.json` 保存已选耳机。
连接成功并出现音频通道后才确认选择已保存；Pi 或耳机重新开机后会自动重连，失败按退避间隔重试。

- **暂时断开**：保留选择与配对，暂停本次服务运行中的自动重连；手动重新连接或服务/Pi 重启后恢复。
- **取消自动连接**：清除默认耳机选择，停止对该设备自动重连；不删除系统已有配对关系。
- **状态显示**：已选耳机、蓝牙连接、音频就绪、保存/自动重连、电量（设备有上报时）及具体错误。
- 蓝牙未就绪时，流程语音遵循既有的扬声器回退策略；音量仍在采集设置中调整。

录制中暂停手动蓝牙操作，状态不会被错误当作“已佩戴”或“已听到”的证明。
没有新耳机在场时，只能验证管理界面与连接逻辑，实际听音需在新耳机连接后完成。

本机选择、BlueZ 密钥及上传 AK/SK 都不进入 Git。上传凭据和耳机选择是两套独立的本机状态。
