# 脑电 / 肌电切换与手动采集流程

GitHub 原 `main` 已改名为 `feat/emg-only`（默认分支）；原脑电分支改名为 `feat/eeg-include`。
两个分支共享经过检查的运行代码，`orangepi/configs/collection_mode.json` 的新站点默认版本不同。
手机切换实际的设备配置和存储配置；切换时关闭旧预览、关闭 HTTP/上传后台并重新加载程序，不在录制现场执行 Git checkout。

## 手机操作

- 总览上方选择“肌电”或“脑电”。肌电模式不启用、打开或保存 EEG；脑电模式在原有相机、肌电、IMU 基础上包含 EEG。
- 13 号初始为脑电；7、11、14 号初始为肌电。重启保留上次手动选择。
- 当前段未处理完或正在上传时先完成/放弃当前操作。准备页和相机检查页原有“放弃本次采集”仍可用；录制黑屏新增“停止并放弃本段”，需要确认。
- 放弃录制先请求 STOP、验证停止回执，等采集进程退出后才清理当前段；已保存的其他段不受影响。停止未确认时保持黑屏、不删除。
- 保存成功（包括待主机 QC）后等待手动点击“准备下一段”。重新准备和正式 START 仍是两次独立操作。
- “重采本段”清理本段后保留原参考任务，等待手动准备；“放弃本段”释放当前参考任务并回到总览。

## 数据隔离

首次初始化把原有目录永久绑定到 `legacy_mode`，保留旧数据、参考图和台账的原路径。
另一版本的配置/图库/运行状态位于 `<project>/profiles/<mode>/`；SD 输出位于原设备目录的 `profiles/<mode>/data/<shift>/`。
因此原始绝对路径凭据无需重写，旧数据不会被移动或重新分类。

另一版本初始图库为空，需在该版本中导入自己的任务包。参考图、任务池、抽样进度、完成台账、今日汇总、回看、上传队列和清理记录分别读取所选版本。
两版可以导入相同图片，但各自独立计数。新段冻结 `collection_mode` 和模式代次；上传目标也包含 `emg` / `eeg` 子目录。
切换后页面自动重载，旧页面请求的模式代次与当前不符会被拒绝，避免旧点击操作到新版本。

代码、Python 环境、相机服务和同一台设备的物理标定文件共享；不会复制另一台设备的标定或脑电帽绑定。
已有 EEG serial 继续严格匹配；未配置 serial 的新脑电配置只在恰好发现一顶兼容 USB 脑电帽时选择它，多顶时拒绝猜测。
脑电保持 CH1–8、250 Hz、原始数据与阻抗流程；13 号的阻抗接受策略继续使用原设置。

## 初始化现有站点

先结束采集并停止采集服务，保留本机配置和 `.venvs`，只更新代码，然后运行：

```bash
python3 tools/configure_collection_profiles.py --legacy-mode eeg  # 原本采脑电的站点
# 原本采肌电的站点用 --legacy-mode emg
```

这个归属一旦设置就不能改成另一模式。后续通过手机切换 `active_mode`，无需更改历史归属。
两种模式均需本机可用的硬件、框架和独立 EEG Python 环境；脑电预检服务保持 `OMNIBCI_ENABLE_IMPEDANCE_PREFLIGHT=1`。
局域网授时继续读取全局控制状态；当前活动模式录制、倒计时、保存或测阻抗时不跳变时间。

验证覆盖临时文件下的隔离与模式往返、错误模式请求拒绝、停止前不删除、待 QC 手动下一段、手机黑屏放弃、准备放弃返回总览及原有 EEG/EMG/QC/黑屏保护回归。
实机模式往返只切换空闲配置，不触发真实录制；佩戴后完整真实采集仍需现场验证。

保留现场较新的启动进度页（`ORANGEPI_EARLY_WEB`）：相机初始化期间可查看启动状态；相机未就绪时不允许录制，按原流程交接给正式控制页。
