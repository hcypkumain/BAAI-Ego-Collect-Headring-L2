# 2026-11-06 脑电版更新

该分支以当前肌电版 main 为基线，恢复并核对 13 号实际使用的 OmniBCI 脑电链路，再合并公共修复。main 不受本分支提交影响。

- 保留独立 EEG SDK 进程、CH1–8、250 Hz、滤波预设、原始 ADC/样本序号与单调时钟证据。
- 保留阻抗 START/END/REVIEW、恢复普通采样、用户确认与正式 START 的门控。13 号现有阻抗接受策略保持原配置，不通过篡改测量值放行。
- EEG 标准化和 PiEegChecker 仍进入完整 QC；也保留通用主机待检与肌电即时检查入口。`emg_only` 仅代表肌电部分已查，其余模态仍待完整检查，不代表 EEG 已通过。
- 肌电可验证的稀疏拼接坏帧在完整备份后修复，支持已观测的 7/24 字节嵌套头形态；重新运行原始 checker。WARN 可继续，ERROR 保留，超过原始 100 ms 阈值的缺口不降级。
- IMU 重复/回退样本按原始规则保留并 WARN，真实缺口及读取/写盘故障仍检查。其他相机/肌电配置不被脑电版本替换。
- 手机端显示肌电左右侧、原因、阈值、发生时间与处理建议；历史回看读取对应的部分 QC 报告。
- 完成阻抗检查、尚未正式开录时，允许跨任务选择参考图，保留准备进程与阻抗证明；录制与屏幕遮黑期间仍禁止切换。
- 保留预览交接、无帧重连及黑屏确认流程，不自动开始正式录制。

## 安装与升级

使用 `bash orangepi/scripts/setup_envs.sh` 创建硬件、框架和独立 EEG 环境。已有 EEG SDK 环境可继续使用，升级代码不应重装 SDK。
历史 13 号的 `.venvs/ros` 实际承载发行版 Python/GI 硬件依赖。原地升级可将 `.venvs/hardware` 指向该环境，既不启动 ROS 服务，也不删除原环境。
新站点应使用本机采集员编号、EEG USB serial/MAC、SD 卡和标定；不能复制另一台设备的校准证明。

## 可选局域网自动授时

授时主机当前有线地址为 192.168.1.118，由它通过无线网络取得公网时间。头环端：

```bash
python3 scripts/install_lan_time.py --server 192.168.1.118
sudo python3 scripts/install_lan_time.py --server 192.168.1.118 --apply
```

先输出安装计划，apply 时备份系统文件。开机有限重试，主机不可达照常采集；空闲时重试校时。录制、倒计时、保存、质检和脑电阻抗测量期间不做跳变校时。chrony 持续平滑校正。
安装授时服务不重启采集或相机服务，不改写历史时间戳。网络重分配地址时应更新授时服务器地址；可为主机网口在路由器设置 DHCP 保留。

## 验证边界

软件回归覆盖脑电格式、8/7 通道历史兼容、STOP 最终门、阻抗恢复、共享 QC、任务选择及手机界面。测试使用临时数据或模拟器，不自动录制真实脑电；实机长时耐久仍属于单独验证范围。
