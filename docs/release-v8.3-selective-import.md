# v8.3 选择性导入与修复状态

## 本次代码变化

U 盘任务包默认合并到现有图库。操作者可以选择一个或多个 ZIP，并可单独勾选旧列表移入回收站；两组选择都默认不勾选。旧列表软删除后仍可从手机回收站恢复。既有图片按归一化内容标识去重，重复图片沿用已有名称等元数据；已在回收站的同内容图片必须先恢复。被选中的系统只读列表仍需先复制参考图，且不能在同一批删除副本。采集中的列表受锁保护，图库版本发生变化时要求重新扫描。

导入合并保留未勾选列表、图片、采集账本、标定和原有抽取设置；已选删除列表仅设置软删除标记，原资源不清除。合并在容量检查、ZIP 校验和并发版本核对后提交，并继续使用旧/新 catalog 与偏好设置备份及恢复 journal。旧版“确认替换”请求不再被接受。

手机端在提交后锁住当前操作，状态未知时不重复发送。页面重开后先查询服务器状态并清除旧 ZIP 与删除选择；服务器仍在处理时不能再次提交。只有已处理状态的更新时间与提交前记录值不同时才解除待确认锁，旧终态不会解锁本次提交。USB 状态接口不可用时仍允许普通图库编辑，USB 导入入口保持禁用。PC 上传 ZIP 与图片原本采用追加语义，本次未改变。

## 状态语义

| 状态 | 含义 |
| --- | --- |
| `idle` | 当前没有导入任务；重开页面须重新扫描和选择。 |
| `building` | 正在校验 ZIP 并构建待提交 catalog；旧库尚未更改。 |
| `ready` | 新内容已校验，等待控制器提交；旧库尚未更改。 |
| `committing` | 正在切换 catalog 和当前列表偏好；若中断由 journal 核对旧/新版本。 |
| `complete` | 选定包已加入，勾选的旧列表已软删除；历史录制和标定不变。 |
| `failed` | 本次导入未完成，旧库保持原状；刷新核对服务器任务状态后可重新扫描。它不表示物理 U 盘或设备故障已经恢复。 |

采集结束状态也要区分：STOP 确认表示停止收尾已获得证据，不代表本段质量合格；结束后 QC 仍可失败。时长至少分为“已保存录制时长”“待 QC 时长”和“QC 合格时长”，不得把已保存或待 QC 直接表述为合格。
