# 头环统一版 · 2026-11-07

版本：`headring-unified-20261107-v2`。维护分支：`feat/unified-headring`。

## 一套程序，两种模式

肌电和脑电不是两份程序或两个部署分支。所有设备运行相同共享代码，手机页面选择实际采集模式。新安装默认肌电；现有设备的 `runtime/collection_profile.json` 优先，升级不改变当前模式或历史数据归属。

必须保留的设备私有内容包括 DEVICE_ID、标定、camd 硬件映射、SD UUID、上传密钥、访问码、ADB 私钥、外设绑定、参考图和任务进度。它们不是需要统一的程序文件，也不进入 Git。

## 纳入的现场修复

- `20261107.2` 模式切换恢复：允许无关状态 revision 漂移，但保留模式上下文、忙状态和录制保护；不自动重复不确定的写请求。
- 快速启动与切换重启页面：先显示启动进度，真实相机、校时和校准就绪后才交接完整控制器。
- 原始 EMG/IMU QC、错误解释、手动开始/停止/保存、参考任务切换及回看修复。
- 台账使用安全的 C YAML 解析器，保留安全加载的后备实现；不缓存删除/失败录制的完成判定。
- 系统日志观察器限制启动积压与事件范围，避免重复扫描全部历史日志。
- USB 手机自动接入：只接受物理 USB Android 手机，保留首次授权、独立 ADB 身份、网页鉴权和录制屏幕保护。
- 受保护的局域网校时：录制/保存或状态不可信时禁止跳变时间；缺少时间服务器时按现有策略降级，不伪造同步精度。

## 验证与限制

发布前检查源文件覆盖与哈希、敏感信息排除、Python/JS 语法、模式切换后端、USB 自动选择/授权/浏览器守卫、17 个屏幕同步场景和录制遮罩。现场核对代码哈希、服务与页面；不能将这些检查代替所有外设连接、正式录制或冷启动验收。

离线设备无法远程更新；相机失效或录制状态不明的原厂设备不能强行迁移。GitHub 的统一分支不等于所有硬件已正常工作。实际设备更新结果另行记录，不把用户数据或密钥放入仓库。
