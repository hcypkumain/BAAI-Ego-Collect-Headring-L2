# 主机手动接收与原始数据交接（v5）

## 操作入口

主机网页只有 **开始接收**、**停止接收** 两个接收控制按钮，不按午间或晚间分时。
首次控制需要主机独立管理员口令；口令不等于云端 AK/SK。LAN 页面不要暴露到公网。
管理员会话、同源校验、CSRF、操作 UUID 和 revision CAS 防止重复点击及旧页面逆转停止。

- 开始接收：扫描授权设备的已闭段，接收完整原始副本。
- 停止接收：停止新的字节传输和新的 Pi 删除授权；已持久化授权的精确事务允许完成 ACK/恢复。
- 停止接收不停止 PC 对已有完整副本的 QC、标准化或独立云端上传。
- 设备范围固定为 13、14、15、17、18、19、20、21、22、23。PC 已存的 7/11 历史包可以上传；不连接它们的设备。

## 三类确认不能混用

1. **原始数据交接**：整段文件集合、大小、逐文件 SHA256 与落盘持久化完成，产生 `raw_handoff_v1` 签名回执。此时可释放对应 Pi 原件，不等 QC。
2. **质量检查**：PC 独立执行 QC；合格、WARN、ERROR 都不能反过来冒充字节交接。Pi 原目录已移除时，结果通过 `post_handoff_qc_v1` 索引回写。
3. **完整云端确认**：精确对象集合及大小一致，小文件 MD5/ETag、大文件 SDK 逐块和整文件 CRC64 校验完成，平台 process/complete API 成功应答后产生签名 `pc_cloud_confirmed_v1` 回执。

云端 STS 不允许 GET 对象，不能宣称云端 SHA256 读回。PC/Pi 字节交接仍逐文件 SHA256。
KS3 分块 ETag 不作为普通 MD5 比较；零字节目录标记通过显式零长度 PUT 保留。

## 保留及容量

- PC 最早清理时间 = **完整云端确认成功时间 + 259200 秒（72 小时）**，不是接收时间、QC 时间或最后一次上传尝试时间。
- 未上传、失败、未确认、缺少签名、磁盘 UUID 变化或文件 SHA 变化，一律保留。
- 清理只作用于签名精确指定的包；原始副本/归档必须另有 raw→archive→standard 关联证明。
- 历史原始备份关联不明确时保留。测试段未获云端确认，保留期不启动。
- 磁盘不足不得提前清理。传输或 QC 写入失败时保留 Pi 未交接原件/PC 已提交副本，显式等待空间；现有版本没有验证多任务容量预留或全天规模吞吐。

十台六路视频按现有四路短测粗略外推，约 **3.96 TB 原始数据/8 小时/天**。约 4 TB 主机盘不足以支持云端成功后 3 天保留及额外副本。
正式全天使用前需要扩容并验证容量背压、双腕相机+肌电+音频长期并发；不要把四路短测当六路全天验收。

## 云端与断点恢复

只操作 `EGOL2`、`EGOL3_hand`：

- 固定 L2 完整包（不含 EEG）：`EGOL2/<标准库相对路径>`，28 文件。
- 固定 L3 完整包（真实八通道 EEG）：`EGOL3_hand/<标准库相对路径>`，30 文件。
- 旧 `EGOL2/pi-collect/...` 保留，不自动删除或覆盖。
- `headring-cloud-uploader.service` 使用既有 SQLite 队列、单实例锁、任务 ID、分块意图和逐文件证明。不要因为控制端 SSH 中断重复启动上传。
- `remote_confirmed` 包跳过；云端成功回执、控制账本和签名密钥放主机内盘。
- SDK 在隔离 Python 3.11 中执行，凭据只在主机私有目录与进程内使用。仅上传进程启用限定域名备用解析，不改系统 DNS/路由，不关闭 TLS 证书校验。

## 相机检查与实测范围

检查页使用短 JPEG 请求及 ImageBitmap/canvas 解码。服务器继续负责新画面完整性、check_id、准备上下文及隐私门禁。
页面切换、黑屏、超时、上下文变化时清除画面并禁用确认，旧响应不能重新显示。

20 号专用测试已完成相机检查、黑屏 ACK、手动 START/STOP/保存、PC 接收/SHA/落盘、Pi 原件删除、PC QC 和结果回写。
实测 10.146 秒，原始 56 文件、68,316,395 字节，传输 11.820 秒；QC 有效 WARN、原始 INFO。仅四路头环相机和板载 IMU，缺腕相机/肌电，因此标准化 blocked、没有上传，属于正确保护。
测试列表已隐藏，PC 档案保留；无需重建或再次开始该段。

## 音频边界

已核验真实 USB capture 接口，20 号五秒原生 PCM/WAV 短采成功：16 kHz、S16_LE、两通道。
这段两通道逐样本相同，不能宣称独立双麦或空间立体声。保留原生数据，不用 monitor、null、播放提示音冒充麦克风。
正式录音和含音频标准档位 **尚未实施/验收**，不能混入旧 28/30 文件档位，不能为旧无声包补假音频。
