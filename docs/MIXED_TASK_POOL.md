# 手机任务池与页面稳定性

进入手机采集页的“任务池 · 导入与隐藏”。勾选的多个列表组成“混合任务池”，每次准备新段时从中抽一张未完成的任务图。沿用未采集优先规则：从未产生采集数据的图优先随机抽取，其次为未成功的 ERROR 图；WARN 仍计为完成。重采保持同一张图。重复资产只进入池一次，并保留所有来源列表标签。

“启用混合抽取”切换当前采集范围到混合池。勾选开关修改后自动保存。新 ZIP 任务包完整导入后自动参与；未完成的导入排除。导入与勾选操作应在设备确认或空闲状态完成。正在准备/采集的资产锁定后，不允许修改其列表的抽取设置。

“隐藏列表”页保留旧列表及任务完成状态，允许查看和恢复。隐藏的列表不出现在常规任务池列表中，也不能通过旧的单列表控制入口进入采集。恢复到可见区后，需要重新勾选才能参与抽取。隐藏操作不修改或删除历史录制。回收站操作仍单独存在。

每个列表的“标签与列表管理”可填写附加标签（逗号分隔，最多 16 个）。列表名称自动作为标签。标签及来源列表冻结在每段 `meta.json` 和标准 `meta.yaml` 的 `reference_selection.asset.tags/source_lists` 中。任务图对应的 YAML/CSV/摆放总览随该段保存到 `reference_bundle/`。混合池的场景资料按本段任务所属列表选择，避免使用另一列表的配置。历史无标签的元数据继续兼容。

页面同步将小状态读取与显示端登记合并，降低并发请求数。浏览器按请求发出时间计算登记有效期，慢响应不能延长过期许可。完整波形/QC 状态读取较慢时，小状态通道仍可独立更新。短暂重新同步会暂停媒体并保留当前页面、列表和表单；整机/控制实例变化或实际任务变化仍会重新建立上下文。START 前遮黑、实际失联遮黑、绘制确认后 ACK 和 STOP 确认规则保持。

控制请求新增 6 秒等待上限，结果未知时通过 Pi 状态继续确认，不自动重复提交。任务池入口合并了重复入口；空闲总览不显示无当前段可放弃的按钮。ZIP 导入位于任务池页上方。

结果页按 `review.session` 标识当前回看批次。服务重启或准备另一段时，历史 QC 会明确标为历史结果；只有同批次的保存回执可以显示“已确认保存”，避免用上一段的回执替当前段背书。

脑电首次连接在原有 5 秒配置握手与 3 秒首帧预算内重发只读配置查询/开始命令，不增加正式录制门限、不重置 USB 集线器。读取错误和最终超时继续报错；扫描诊断保存到 `orangepi/runtime/diagnostics/eeg-startup/`，最多保留 30 份。自动重新扫描仍只发生在空闲且无采集 worker 时。该修改需在脑电 USB 可接入时完成硬件验收，软件测试不能替代硬件验证。
