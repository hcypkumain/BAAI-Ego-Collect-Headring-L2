# 数据侧别回溯更正库

`emg_role_correction.py` 提供已获操作者明确授权的肌电左右身份更正函数，不会自动运行。
操作前必须确认具体采集日期、会话清单、两路实际佩戴方向、采集进程已退出、上传队列空闲，
并持有每段锁；不能仅凭接收器序列号推断佩戴侧别。

更正仅交换 EMG 及同手环 IMU 的保存角色与元数据，不改信号值、序号或时间戳，不更改腕相机。
原流目录在同卷的采集树之外保留；原始插入证明保留，并明确标识事后操作者更正。
既有 QC 结论只跟随所属流重新标注，不把 ERROR 或未完成保存的段提升为成功。

每段有完整标记以防重复执行后反向交换；中断恢复依靠外部事务日志和原目录。
测试位于 `orangepi/tests/test_emg_role_correction.py`，全部使用合成数据。
实际会话清单、信号、原始备份、密钥和本次更正结果都不在仓库中。
